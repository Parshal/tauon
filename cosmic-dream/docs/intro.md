## Cosmic Dream (TL;DR)

Cosmic Dream is a drop-in theme module that pairs a WebGL2 nebula backdrop with a HUD control dock and hue-animated DOM cards. `src/index.js` boots the `CosmicEngine`, which stitches together the renderer, reactive store, UI sliders/toggles, and CSS hue animator so any host page can gain the "cosmic" skin without touching its own layout.
