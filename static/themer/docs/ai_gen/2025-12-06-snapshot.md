# Cosmic Dream Snapshot (2025-12-06)

## Topology
- Entry bootstrap `src/index.js` instantiates `CosmicEngine`, auto-boots on DOM ready, and exposes the engine globally for debugging. @cosmic-dream/src/index.js#1-14
- `CosmicEngine` wires `NebulaRenderer`, `Styler`, and the HUD `ControlPanel`, manages resize + visibility observers, and runs the RAF loop that feeds FPS metrics back into the UI. @cosmic-dream/src/core/engine.js#1-75
- Configuration: `PARAMS` + `PASS_FLAGS` define every slider/toggle, `getDefaults()` seeds `store.data`, and `State` pushes updates to subscribers on change. @cosmic-dream/src/data/config.js#1-55 @cosmic-dream/src/core/state.js#1-34
- Control surface: `ControlPanel` renders the `Stars` group, binds sliders/toggles to `store.set`, tracks dirty config hashes, and persists snapshots via `localStorage`. @cosmic-dream/src/modules/ui.js#1-379
- Rendering: `NebulaRenderer` builds a fullscreen WebGL2 canvas, compiles a `ShaderPass` for `stars.frag` with `STAR_UNIFORMS = [zoom, starDensity, starTwinkle, starZoom]`, injects `seamDebugEnabled` dynamically, and composites to screen via `CompositePass`. @cosmic-dream/src/modules/renderer.js#12-252
- Shader assets stream via `loadShaderSources()` which caches fetches for the fullscreen vertex plus star/composite fragments stored in `src/shaders`. @cosmic-dream/src/data/shaders.js#1-35 @cosmic-dream/src/shaders/fullscreen.vert.glsl#1-8 @cosmic-dream/src/shaders/stars.frag.glsl#1-119 @cosmic-dream/src/shaders/composite.frag.glsl#1-14

## Runtime Flow
1. Module load seeds `store` with defaults so renderer, UI, and Styler share the same reactive data object. @cosmic-dream/src/data/config.js#1-55 @cosmic-dream/src/core/state.js#1-34
2. `engine.init()` constructs the renderer/UI/styler trio, registers a resize handler plus an `IntersectionObserver`, and immediately sizes the canvas. @cosmic-dream/src/core/engine.js#19-43
3. Each RAF iteration (`loop`) accumulates FPS samples, updates the HUD label, advances the renderer with elapsed seconds, then ticks the Styler. @cosmic-dream/src/core/engine.js#55-74
4. `NebulaRenderer.render()` pulls `store.data`, skips the star pass when `starEnabled === false`, otherwise runs `ShaderPass.render(time, data)` to an offscreen FBO and feeds that texture into the composite pass targeting the default framebuffer. @cosmic-dream/src/modules/renderer.js#105-252
5. The HUD reflects changes via `store.subscribe` (`syncControls`, `syncToggles`, `updateBlendLabel`), while user input propagates back through `store.set`/`setAll`, keeping uniforms and UI aligned. @cosmic-dream/src/modules/ui.js#200-305

## Shader Notes
| Uniform(s) | Source | Effect |
| --- | --- | --- |
| `u_res`, `u_time` | @cosmic-dream/src/shaders/stars.frag.glsl#6-8 @cosmic-dream/src/modules/renderer.js#61-136 | `ShaderPass` writes framebuffer size + elapsed seconds each draw so the star shader can derive aspect-correct UVs and time-driven twinkle.
| `u_starDensity`, `u_starTwinkle`, `u_starZoom` | @cosmic-dream/src/shaders/stars.frag.glsl#10-95 @cosmic-dream/src/modules/renderer.js#12-135 | Values come straight from the store via `STAR_UNIFORMS`, controlling lattice occupancy, per-cell twinkle mix, and zoom attenuation before hashing cells.
| `u_seamDebugEnabled` | @cosmic-dream/src/shaders/stars.frag.glsl#15-113 @cosmic-dream/src/modules/renderer.js#201-205 | Dynamic uniform toggles a checker overlay and magenta seam mask to visualize hash cell edges during debugging.
| `u_starTex` | @cosmic-dream/src/shaders/composite.frag.glsl#6-13 @cosmic-dream/src/modules/renderer.js#145-174 | Composite pass samples the latest star framebuffer (or dummy fallback) and blits to the backbuffer.
| `u_contrast` | @cosmic-dream/src/shaders/composite.frag.glsl#6-13 @cosmic-dream/src/modules/renderer.js#145-174 | Store-driven contrast exponent applied post-sampling to control star bloom intensity.
